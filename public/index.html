How I build

The AI reads. Code checks.

Models are good at reading messy things and bad at sums. So the model turns a photo into lines, and ordinary code decides what's wrong.

Show the source.

An answer you can't check isn't worth much. Summaries link to the exact second in the video; bill checks show the line and the math.

Write down what broke.

Every project keeps notes on what failed and why. The failures are usually the most useful part.

I'm happy to compare notes, or send an invite if you'd like to try the apps with your own bills and searches.
